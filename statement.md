# VaultX – Project Statement

## 1. Problem Statement

VaultX is a Python-based desktop banking simulation designed to provide a simple and secure way to perform common banking operations. It allows users to create accounts, log in, manage their PIN, deposit and withdraw money, transfer funds, view transaction history, and generate account reports.

The project demonstrates how Python can be used to build a modular application with database management, authentication, validation, calculations, reporting, and a graphical user interface.

## 2. Project Scope

The project covers the development of a simulated banking system for educational purposes. It includes user authentication, account management, banking transactions, transaction records, reports, calculations, input validation, and data storage using SQLite.

VaultX is intended only as an educational simulation and is not designed for handling real financial transactions or sensitive banking information.

## 3. Target Users

* Students learning Python programming and application development
* Users who want to demonstrate basic banking workflows in a simulated environment
* Evaluators reviewing Python programming concepts such as functions, modules, classes, databases, validation, and exception handling

## 4. High-Level Features

* User registration and login
* Secure PIN handling
* Account management
* Deposit and withdrawal
* Money transfer between accounts
* Transaction history
* Account and transaction reports
* Financial calculators
* Input validation and error handling
* SQLite database storage
* Graphical user interface using Tkinter
* Automated unit testing

## 5. Project Objectives

* Apply Python programming concepts in a complete project.
* Build a modular and maintainable application.
* Demonstrate database connectivity using SQLite.
* Implement authentication and input validation.
* Handle common banking operations in a simulated environment.
* Provide reports and useful financial calculations.
* Practice testing and error handling in Python.
